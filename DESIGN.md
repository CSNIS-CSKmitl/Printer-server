# CS-KMITL Print Server (`DESIGN.md`)

Inherits the root [CS-KMITL Design System](../DESIGN.md).

## Direction

- **Product**: Department print queue, staged document upload, and student/teacher quota management.
- **Character**: `utilitarian, exact, calm` — clear job queue and quota telemetry.
- **Moments**: The print queue table and student quota bar with live job status.
- **Signature**: Hairline 1px queue rows, `tabular-nums` page quotas, and crisp semantic status badges.
